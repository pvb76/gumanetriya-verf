# Чек-лист публикации

Открыт 25.11.2026 по слову Капитана: «как только почувствуешь, что ок, публикуй». Перед открытием история сжата в один чистый коммит, прежняя хранится в приватном кабинете.

| Пункт | Итог | Как проверено |
|---|---|---|
| Секреты (ключи GitHub, OpenAI, AWS, Google, токены Telegram, приватные ключи) | чисто | поиск по шаблонам во всех файлах и в единственном коммите |
| Ключи входа (VK, Google, Яндекс, Telegram) | в коде нет | живут только на сервере в config.json; в репозитории лишь их чтение |
| Почты, телефоны, ID чатов, IP сервера | заменены | `{{ПОЧТА_СВЯЗИ}}`, `{{ПОЧТА_ФОМЫ}}`, `{{KWORK_URL}}`; поиск по маскам пуст |
| Ссылка на Kwork | убрана | заменена на `{{KWORK_URL}}` |
| Имя бухгалтера бюро | убрано | везде «бухгалтер», город убран; снимки стола бюро не публикуются |
| Чужие снимки и примеры MotionSites | убраны | `media/` и `examples/` удалены: по их LICENSE.txt распространять нельзя; оставлены только наши правила (MIT) со ссылкой на motionsites.ai |
| Снимки «до/после» | только сайт и панели | без данных клиентов |
| Лицензия | есть | `LICENSE`: код MIT, тексты CC BY 4.0 |
| README «для людей» | есть | `README.md` |

## Что следить дальше
- Каждое новое зеркало с живого сервера — через замену личных данных на заготовки и повторный поиск по маскам.
- Если в репозиторий попадёт секрет — сразу менять сам ключ, а не только удалять файл.

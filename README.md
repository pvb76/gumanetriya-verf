# Верфь Гуманетрии — исследование и исходник

Как построить и вести небольшое дело в любой нише в России и странах СНГ силами одного человека и ИИ-помощников: сайт, который продаёт; бюро, которое ведёт дела законно; штурманская, которая честно считает результат.

Это не теория: всё здесь снято с работающей системы [gumanetriya.ru](https://gumanetriya.ru) по состоянию на 25.11.2026, с проверкой каждого шага.

## Принципы
1. Сделано только то, что проверено; в отчёте всегда «проверено (как)» или «не проверено (почему)».
2. Факт со ссылкой отделяется от гипотезы.
3. Данные клиента не покидают его дело; в исходниках нет ни одного настоящего контакта.
4. Цифры законов сверены с первоисточниками на 25.11.2026; перед применением — сверить заново.

## Что не входит
Ключи, пароли, адреса панелей, данные клиентов бюро и личная переписка. Их нет в репозитории и не будет.

# Ветка «Бюро бухгалтера»

Стол бюро — веб-приложение на Python (один файл, без внешних фреймворков), где ведутся клиенты, документы, сроки, загрузки и корзина, а помощница Полина отвечает голосом и текстом.

## Главный экран (проверено 25.11.2026)
Пять крупных элементов: поле Полины (голос, файл, «Спросить»), «Клиенты», «Сроки и задачи», «Загрузки», «Корзина». Остальное — под «Ещё». Проверено на 375 px, ошибки словами с подсказкой, что делать.

## Отделы
Восемь отделов в [otdely/](otdely/): экономический, налоговый, юридический, персональные данные и безопасность, кадровый, реклама и маркировка, госрегулирование, СНГ и ЕАЭС. Полина видит оглавление в каждом разговоре и открывает нужный отдел по запросу. У каждой цифры — ссылка на первоисточник и дата сверки.

## Состав
- `ishodnik/byuro-stol.py` — стол (контактная почта заменена полем).
- `znaniya-poliny/` — как работает бюро, приём клиента, ядро Полины. Карта клиентов и сроки клиентов не публикуются.

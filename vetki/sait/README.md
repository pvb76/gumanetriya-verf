# Ветка «Сайт»

Витрина услуг, на которой человек выбирает услугу, видит цену и оплачивает, не уходя в мессенджер. Состояние снято с gumanetriya.ru 25.11.2026.

## Состав исходника
- `index.html`, `uslugi.html`, `zakaz.html`, `primery.html`, `svyaz.html` — страницы.
- `magazin.js`, `korzina.js` — каталог и корзина; `chat.js` — чат с роботом (n8n, поля {{N8N_WEBHOOK_CHAT}}, {{N8N_WEBHOOK_GOLOS}}).
- `oferta.html`, `politika.html`, `soglasie.html` — документы (перед запуском сверить с [03-yurist](../byuro/otdely/03-yurist.md) и [04-dannye](../byuro/otdely/04-dannye.md)).
- `style.css`, `vitrina4.css`, `assets/` — стиль по [stil/STIL.md](../../stil/STIL.md).

## Что не входит
Картинки, видео и шрифты (берутся из своего хранилища), серверная часть оплаты (n8n и платёжный шлюз настраиваются отдельно), секретные панели.

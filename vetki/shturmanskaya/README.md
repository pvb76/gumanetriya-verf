# Ветка «Штурманская»

Аналитика без платных сервисов: сбор раз в сутки (сайт — каждый час), страницы в стиле сайта по закрытой ссылке.

## Панели
- «Наши каналы» (`stat_panel.py` + `kanaly_panel.py`): одна таблица по площадкам — люди, просмотры, заявки, оплаченные заказы за 7 и 30 дней; у каждой строки дата среза и источник; кнопки «Копировать таблицу» и «Скачать CSV для Excel» (UTF-8 с BOM, разделитель «;»); вывод из пяти строк с пометкой «факт» или «гипотеза».
- «Сайт и бюро» (`sait_panel.py`): люди по журналу сервера, путь покупателя, заказы из n8n, стадии дел бюро (только количество).
- «Что в мире» (`mir_panel.py`): спрос на биржах и в лентах.
- Общий стиль — `panel_stil.py`.

## Источники
| Тип | Площадки |
|---|---|
| открытые данные | Telegram (t.me/s), YouTube, RUTUBE, MAX (подписчики), журнал сайта |
| кабинет по API | Авито (просмотры и контакты), Lava (продажи), n8n (заказы, диалоги чата), ВК (подписчики) |
| кабинет, срез вручную через браузер | YouTube Studio, Студия RUTUBE, Дзен-студия, Kwork, FL.ru — файл `kabinet_ruchnoy.primer.json` |
| нет доступа | всё остальное; панель пишет «нет доступа» и как подключить |

## Правила подсчёта
- Пробы владельца не считаются продажами; отменённые заказы показываются отдельно.
- Если истории меньше окна, рядом с числом пишется «(с ДД.ММ)».
- Рекламный бюджет — не продажа.
